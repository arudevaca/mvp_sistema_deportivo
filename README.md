# mvp_sistema_deportivo

# ⚽ Sistema Integral de Gestión Deportiva (MVP)

Plataforma web para la gestión centralizada y segura de fichas de jugadores, clubes, documentos y auditoría de cambios. Diseñado para optimizar la administración institucional y cumplir con la trazabilidad exigida por las regulaciones deportivas.

---

## 🚀 Características Principales

* **Autenticación y Control de Acceso (RLS):** Seguridad a nivel de base de datos para garantizar la privacidad de los datos entre clubes.
* **Gestión de Jugadores y Clubes:** Creación, edición y visualización detallada de fichas técnicas y administrativas.
* **Gestión de Documentos:** Carga y consulta de documentos adjuntos (C.I., certificados médicos) en almacenamiento seguro.
* **Auditoría e Historial de Cambios:** Registro automático mediante *triggers* para trazabilidad completa de modificaciones.
* **Roles de Usuario:** Permisos diferenciados según perfil (Administrador de Club, Cargador).

---

## 🛠️ Tech Stack

* **Frontend:** Vue 3 (Composition API / `<script setup>`), Vue Router
* **Backend & Database:** Javascript, Node.js, Express.js, Supabase (PostgreSQL, Auth, Storage)
* **Diseño UI/UX:** Figma
* **Control de Versiones & Deploy:** Git, GitHub, Vercel / Netlify
